---
name: sage-fair-data
description: Assess or package scientific data for findability, accessibility, interoperability, and reuse.
---

Inventory the intended audience, data types, metadata, access constraints, and
existing domain standards. Record stable identifiers, units, schema, reference
versions, processing provenance, checksums, and reproduction commands where
appropriate. Prefer the project's established machine-readable metadata format
over a new parallel manifest.
Validate representative records and links against the actual schema and domain
requirements. Distinguish metadata availability from permission to access the
underlying data. Document the real license/access terms and missing information;
do not invent a license or publish a restricted dataset to satisfy accessibility.
Separate a shareable results package from restricted source data and execution
records. Check that shared metadata does not reveal private identifiers or paths.
Report concrete gaps and verifiable improvements rather than an unsupported
FAIR compliance score.
