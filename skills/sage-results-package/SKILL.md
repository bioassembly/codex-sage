---
name: sage-results-package
description: Package completed pipeline outputs into a portable client-facing results directory.
---

Inspect the requested audience and output contract. Create a manifest and a clear,
optionally numbered sequence from curated inputs to final results. Preserve original
outputs; copy only the chosen deliverables and required interpretation metadata.
Separate raw and normalized tables and define units, columns, sample mappings,
reference versions, filters, and denominators. Sanitize internal absolute paths and
private identifiers according to the delivery scope. Use physical files rather
than links that will break when moved.
Keep credentials, runtime caches, proprietary execution scripts, and internal
environments out of a client delivery unless explicitly requested and authorized.
For a reproducible research delivery, include the authorized code/environment
artifacts; do not mistake a client-results convention for a universal code ban.
Check copied file counts, readable formats, empty files, broken links, and checksums
where useful. Write a README that explains what to open and what each result means.
Do not upload or publish the package unless the user requested that action.
