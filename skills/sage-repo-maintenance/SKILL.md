---
name: sage-repo-maintenance
description: Improve repository reproducibility, contributor documentation, CI, or release maintenance when requested.
---

Start from the actual install, run, test, update, and restore paths. Verify the
documented commands in an isolated environment where practical. Make runtime
requirements and maintained source locations discoverable. Keep secrets, machine
paths, caches, and generated outputs outside source control.
Match existing structure and licensing. Add CI for meaningful supported checks,
pin executable dependencies appropriately, and document how to review updates.
Check links, examples, configuration preservation, and failure recovery. Include
provenance for third-party material and distinguish modified adaptations from
upstream distributions. Do not invent release claims, benchmark improvements,
security guarantees, or badges. Add community templates only when they support
the requested collaboration workflow; avoid a generic documentation expansion.
